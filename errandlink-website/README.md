# ErrandLink website 

A responsive HTML, CSS and JavaScript prototype for an errand-service platform.

## Run locally
1. Download and extract `errandlink-website.zip`.
2. Open `index.html` in a browser. For a VS Code workflow, install/use Live Server and choose **Open with Live Server**.

## Features
- Front-page profile form: name/username, email, phone, national ID field and product-photo browse/upload.
- Service catalogue with illustrative KSh starting prices.
- Search and category filters.
- Choose a service and preview an errand request.
- Online video/chat or physical public-meeting preference.
- Preferred date/time and location fields.
- Responsive layout and FAQ.

## Important prototype notes
- This is a front-end demo only. It does not create accounts, verify identity, send messages, book a real runner/seller, process payments or store requests.
- Do not enter a real national ID number in the demo. A production system should minimise identity data collection and use secure server-side storage, access controls, consent, retention rules and appropriate Kenyan data-protection compliance.
- Prices are illustrative sample starting fees in Kenyan shillings, not verified market rates. Adjust them to your actual operating costs and service area.
- Before launch, add a backend/database, authentication, identity-verification provider if genuinely necessary, runner/seller verification, messaging/notifications, payment integration, order status tracking, cancellation/dispute/refund rules and privacy/terms pages.
